# Zen Planner

Single-file planner (HTML, CSS, vanilla JS). Data is saved in your browser's localStorage.

Deploy: push `index.html` and `CNAME` to a GitHub repo, enable Pages (Settings > Pages),
and add a DNS CNAME record: `zen` -> `<your-github-username>.github.io`.
Use History > Backup or restore to keep a copy of your data.
